# KIFARO

KIFARO is a medical education platform for undergraduate medical students.

## Current MVP
- Student Dashboard
- Curriculum
- AnatoMate by KIFARO
- Topics
- Interactive Learning Room
- KIFARO Studio
- My Library / Favorites
- English + Arabic UI
- RTL support
- Four color themes
- Progress and preferences saved with localStorage
- Responsive desktop/tablet/mobile layout

## Stack
React + TypeScript + Vite + React Router + Lucide Icons

## Run locally
```bash
npm install
npm run dev
```

## Quality checks
```bash
npm run typecheck
npm run build
```
